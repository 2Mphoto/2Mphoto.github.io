# Dossier — Séries (galerie)

Ce dossier contient les photos affichées dans le viewer de galerie (page Séries).

Les fichiers sont listés dans `manifest.json` — c'est lui qui contrôle quelles photos apparaissent et dans quel ordre.

## Ajouter ou changer des photos

1. Ajoutez vos fichiers JPEG dans ce dossier
2. Ouvrez `manifest.json` et ajoutez le nom du fichier dans la liste

Exemple de `manifest.json` :
```json
["photo1.jpg", "photo2.jpg", "photo3.jpg"]
```

**Format recommandé :** JPEG, largeur minimum 1400px.
